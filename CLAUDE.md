# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
# Install dependencies
pip install -r requirements.txt

# Run on schedule (waits until RUN_HOUR each day)
python agent.py

# Run immediately
python agent.py --now
```

## Architecture

Single-file agent (`agent.py`) with four scraping functions + two Claude API calls per run:

1. **Scraping** — `search_whop`, `search_reddit`, `search_web`, `search_twitter` run for each of 10 randomly sampled keywords, with `time.sleep` between calls to avoid rate limits. Twitter uses public Nitter instances as a proxy.
2. **Claude filtering** (`analyze_with_claude`) — raw results are chunked into batches of 30 and sent to `claude-sonnet-4-20250514` with `RESEARCH_AGENT_PROMPT`. Claude must return a JSON array with no extra text; the code strips markdown fences and parses it. Only results meeting the free-entry criteria survive.
3. **Discord delivery** (`send_discord_embed`) — sends two embeds: a summary (generated by a second Claude call with `SUMMARY_AGENT_PROMPT`) and a fields embed with up to 20 partner leads.
4. **Logging** — each run writes a date-stamped `.log` file and a `results_YYYY-MM-DD.json` to `logs/`.

Prompts live in `agents/prompts.py` (`RESEARCH_AGENT_PROMPT`, `SUMMARY_AGENT_PROMPT`).

## Configuration

- `.env` — `ANTHROPIC_API_KEY`, `DISCORD_WEBHOOK_URL`, `RUN_HOUR` (24h, default `9`)
- `keywords.json` — `keywords` array (search terms) and `exclude` array (titles containing these strings are dropped before Claude sees them). 10 random keywords are sampled per run.

## Filtering logic

Claude only includes a result if it has a free Discord invite, a free Whop trial, or a public forum/subreddit. Fully paid groups are excluded. The `exclude` list in `keywords.json` provides a pre-Claude keyword filter on result titles.
